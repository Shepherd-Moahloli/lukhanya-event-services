# Lukhanya Event Services

## Project Description
Lukhanya Event Services is a catering and event management company based in Soweto, South Africa. This project showcases the services offered, including bespoke catering, event management, sound, stage, lighting, and more. The website is designed to provide a seamless experience for users looking to plan their events.

## Project Structure
```
lukhanya-event-services
├── css
│   └── main.css        # Contains all the CSS styles for the website
├── index.html          # Main HTML document for the website
└── README.md           # Documentation for the project
```

## Setup Instructions
1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd lukhanya-event-services
   ```

2. **Open the Project**
   Open the `index.html` file in your web browser to view the website.

3. **Modify Styles**
   To change the styles, edit the `css/main.css` file. All CSS styles are contained within this file.
